# Changelog

## [1.0.0] - 2026-11-04

Initial release of BOAF, including:

- Raw TCP and structured HTTP testing modes.
- Progressive payload fuzzing with configurable worker concurrency.
- Target liveness checks to distinguish transient failures from confirmed downtime.
- Static buffer-overflow injection with configurable testing parameters.
- TLS support, including controlled self-signed certificate acceptance.
- Linux and Windows release binaries built through GitHub Actions.
